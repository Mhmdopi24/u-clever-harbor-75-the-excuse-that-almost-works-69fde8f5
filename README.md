Entry for the make.fun bounty [The Excuse That Almost Works](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5): one line a gamer texts the boss to skip work on GTA 6 launch week, at most 20 words, judged by a tired manager who believes almost none of them.

`main.ts` (Node, standard library only) writes the excuse to `/output/entry.txt`:

> Sorry — boiler's packed in, plumber needs me in to sign off the repair, back online right after lunch.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
